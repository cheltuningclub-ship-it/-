# Интеллект Медиа

Анимированный сайт агентства рекламы на LED-экранах в Оренбурге.

## Эффекты

- **Параллакс мыши** — слои героя смещаются за курсором
- **Параллакс скролла** — фон движется медленнее контента
- **Spotlight-reveal** — детали галереи проявляются под курсором
- **3D tilt** — блоки услуг реагируют на наведение
- **Magnetic CTA** — кнопки слегка тянутся к курсору
- **Scroll reveal** — секции появляются при прокрутке

## Производительность

- Статический HTML/CSS/JS без сборки и тяжёлых библиотек
- Локальные сжатые изображения, `preload` героя, `loading="lazy"` ниже
- Только GPU-friendly `transform` / `opacity`
- `requestAnimationFrame` для мыши и скролла
- Поддержка `prefers-reduced-motion`

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx --yes serve .
```
